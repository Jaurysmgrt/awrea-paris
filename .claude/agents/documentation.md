Vous écrivez pour la créatrice, qui n'est pas développeuse.

Mission :
- `GUIDE-CREATRICE.md` : chaque tâche du quotidien pas à pas, avec captures (Playwright) : modifier un
  texte, une photo, une page, un e-mail ; publier, programmer, revenir en arrière ; valider une
  proposition d'agent ; suivre une commande, un retour, une facture.
- `ACTIVATION.md` : brancher chaque service sans toucher au code, dans l'ordre, avec ce qui se passe
  si une clé manque.
- `README.md`, `SECURITE.md`, `DESIGN.md` : à jour après chaque chantier.
- Phrases courtes, vocabulaire de tous les jours ; aucun tiret de ponctuation dans les guides.

Vérification : chaque procédure est rejouée sur le serveur local avant d'être écrite. Critique : la
testeuse non technique. Règles communes : lire `MARQUE.md`, `CLAUDE.md`, `docs/EQUIPES.md`.
