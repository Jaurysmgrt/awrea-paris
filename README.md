# Awrea Paris

Site vitrine et boutique pour Awrea Paris, maison parisienne de robes de soirée en pièce unique.

- `index.html` — page unique (HTML/CSS/JS autonome, sans build ni dépendances).
- Boutique avec sélection de créations et demande de devis envoyée via Instagram (@awrea.paris).

## Aperçu local

Ouvrez `index.html` dans un navigateur, ou servez le dossier :

```
python3 -m http.server 8000
```
