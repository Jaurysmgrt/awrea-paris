# Logo Awrea Paris — emplacements

Déposez ici les fichiers officiels (SVG monochromes, fond transparent) :

- `logo.svg` — monogramme « AW » + « PARIS » sous le monogramme
- `monogram.svg` — monogramme « AW » seul
- `wordmark.svg` — logotype horizontal (facultatif)

Puis indiquez leurs chemins dans `content/brand/assets.ts` (ex. `src: "/brand/logo.svg"`).
Le favicon se remplace dans `app/icon.svg` et `app/apple-icon.png`.
